# Nom du plugin guitare → MIDI : candidats (8 octobre 2026)

Le plugin VST3 (effet audio avec sortie MIDI) aura un nom à lui, distinct de JAMRACK
(le rack web). Recherche faite le 8 octobre 2026 : 3 agents ont proposé 49 noms
(jeux de mots français/latins, mots inventés, images), 4 agents les ont vérifiés sur
le web (produits musicaux, plugins, applis, sociétés françaises, marques dans TMview,
domaines), un dernier a classé les meilleurs ; les trois premiers ont été recherchés
une seconde fois (aucune page avec cette orthographe).

**Ce n'est pas une recherche d'antériorité juridique.** Avant d'adopter un nom :
recherche INPI / EUIPO / USPTO (ou TMview) en classes 9, 15, 41 et 42, puis réserver
tout de suite le .com, le .fr et le nom sur GitHub.

## Les 8 retenus

| Nom | Sens | Réserve trouvée |
|---|---|---|
| **Pizzicorde** | pizzicato (corde pincée) + corde ; on entend aussi « chord » (accord) | aucune ; .com et .fr libres |
| **Corduit** | corde + conduit : ce qui amène la corde jusqu'au MIDI | prononciation anglaise hésitante ; un petit projet GitHub sans rapport ; .com et .fr libres |
| **Doppelfret** | le « double » (doppelgänger) MIDI de chaque note frettée | mot d'origine allemande ; .com et .fr libres |
| **Notacorde** | note + corde : la corde qui écrit des notes | proche de *Notochord* (projet MIDI libre, 2022) ; .com et .fr libres |
| **Plectrix** | plectre (médiator) + -ix (clin d'œil à benasterisk) | marque allemande expirée (2005) ; **.com pris** (inactif) ; .fr libre |
| **Chantecorde** | « chante, corde » : la corde qui chante à travers les synthés | long, difficile en anglais ; .com et .fr libres |
| **Stringua** | string + lingua : la corde qui parle la langue des synthés | prononciation française hésitante ; .com et .fr libres |
| **Ondicorde** | onde + corde ; clin d'œil aux Ondes Martenot | évoque plutôt un clavier ancien ; .com et .fr libres |

## Écartés (extraits)

- **Conflit** : Cordeau (marque logicielle déposée en France en septembre 2026),
  Lyrode (appli musicale existante), Chrysopée (nom d'artiste), Écholalie, Mediatone,
  Pickscribe, Fretglyph, Pinchord, Corde Sensible, Polyphème, Hexalo, Athanor, Feu Follet…
- **Douteux** : Fretscribe (.com réservé en 2025), Pickwire (.com à vendre), Bendika et
  Glyssa (.com pris), Translyre (société de transport), Truchement, Ventriloque, Rosace,
  Sillet, Passeur, Calque (mots courants, impossibles à protéger), Parlecorde (« paracorde »),
  Cordeglot (« glotte »).
