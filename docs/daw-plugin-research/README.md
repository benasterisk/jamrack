# Notes de recherche derrière `docs/daw-plugin-feasibility.md`

Six notes de travail (en anglais, sources consultées le 7 octobre 2026) produites par
des agents de recherche indépendants, puis relues par deux critiques adversariaux
avant la rédaction du rapport. Elles contiennent les citations et les liens que le
rapport résume ; elles ne sont pas des décisions.

| Note | Sujet |
|---|---|
| `formats-hosts.md` | Formats de plugins (VST3, AU, AAX, CLAP, VST2) et sortie MIDI par hôte |
| `existing-products.md` | Produits existants (Jam Origin MIDI Guitar, Dubler, matériel hexaphonique…) |
| `frameworks.md` | JUCE, iPlug2, DPF, nih-plug, clap-wrapper, Cmajor ; licences, signature, distribution |
| `midi-latency.md` | Ports MIDI virtuels, ASIO / WASAPI / CoreAudio, latences mesurées navigateur vs DAW |
| `portability.md` | Lecture du code JAMRACK à porter (fichiers, lignes, dépendances, oracle d'équivalence, coût mesuré) |
| `daw-workflows.md` | Mode d'emploi par DAW (Live 12 pas à pas, Logic, Cubase, REAPER, Bitwig, FL, Studio One, Pro Tools) |
